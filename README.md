# Frutiger Aero Workspace 9.0

A major feature rebuild based on the available 5.3 archive.

## Update highlights
- Shared Victory and Game Over presentation across arcade games, with game-specific outcomes.
- Macintosh-style white startup screen using the bundled Finder icon and `loading.mp3`; the greeting uses Times New Roman and fades in with the startup audio. Browsers may require a tap before audio can autoplay.
- Frutiger Aqua, Festive, and Metro animated visual add-ons, with decorative layers kept behind the interface.
- Fish Aquarium mode controls, ten Classic levels, Endless red hazards, and local quest tracking.
- AeroVice City expanded glass-building cityscape, blue/green police pursuit, generated original music, and a custom audio file picker.
- Ten distinct original generated Aero Dash music patterns.
- Redesigned Aero Playlist landscape and home-screen Discord community tile.

## Run locally
`npm install` then `npm start` (or the start command listed in `package.json`).

This build is a best-effort 9.0 rebuild from the 5.3 archive, not a byte-for-byte continuation of the unavailable 8.1 Fixed ZIP. Test on target mobile browsers before publishing.
