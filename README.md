# Frutiger Aero Workspace 10.0

A nostalgic Frutiger Aero desktop and arcade workspace.

## Run locally

- Install Node.js 20 or newer.
- Run `npm install`.
- Run `npm start`.
- Open `http://localhost:3000`.

## 10.0 update

- Shared arcade Victory and Game Over windows and a Vista-inspired game lobby HUD.
- Macintosh startup audio begins directly from the first user tap, with a visible retry control.
- AeroVice City road-grid driving, road-following police, wanted stars, a ten-car garage, previews, local credits, and a dodge-cops mission.
- A playable Feed the Fish mini-game on the Aquarium page.
- Existing 9.0 content, assets, and project structure retained.

Game progress, car purchases, and local settings are stored in the browser on the current device.
