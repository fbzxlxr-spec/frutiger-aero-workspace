# Frutiger Aero Workspace 5.0

A Node.js + Express + Socket.IO desktop-style web workspace.

## Deploy on Render
- Runtime: Node
- Root Directory: leave blank
- Build Command: `npm install`
- Start Command: `npm start`
- Node: 20 or newer

## Workspace 5.0 update
- Vista-era glossy glass panels, dimensional buttons, reflective surfaces and realistic bubble styling.
- Eight selectable visual variants: Frutiger Aero, DORfic, Eco, Aqua, Metro, Dark Aero, Festive and Technozen.
- MSN Buddy and Fishy assistant personality selector. MSN Buddy is the default.
- Aero Playlist replaces the old music title.
- Fish Aquarium is launched from the Arcade and retains Classic, Timed and Endless modes.
- AeroVice City receives a top-down coastal boulevard visual redesign with touch-friendly directional controls.
- Arcade tiles and game canvases receive a consistent Windows Vista-era visual treatment.
- Built-in Aero Document editor with local saving and text export.
- Version history selector for versions 5.0, 4.0, 3.2, 3.0, 2.0 and 1.0.

## Important notes
- The VERSION APKS setting is a version history selector. This ZIP does not contain Android APK installers or the historical builds.
- The document, theme, profile and local preferences are saved in the visitor's browser.
- Community chat and Fan Art use the existing 4.0 in-memory server features. Messages/posts can reset on server restart or redeploy. These features need active adult moderation before school-wide use.
- AI requests use the server-side OpenAI Responses API. An adult administrator must set `OPENAI_API_KEY` in Render Environment. Never put API keys in browser code or GitHub.
- Without an API key, AI runs in demo mode.
- The game library keeps the existing 4.0 game mechanics while refreshing the game presentation. AeroVice City has a redesigned coastal-city scene and controls; this is a visual/playability improvement, not a full commercial-scale GTA remake.
- Keep the 4.0 Render service as a backup until 5.0 has been deployed and tested.
