# Workspace 5.3 • Vista Aero Edition

Workspace 5.3 is built on the supplied Workspace 5.2 package. It preserves the 5.2 app and server, then adds the new visual and gameplay upgrades described in README.md.

## Deploying

- Runtime: Node
- Build command: `npm install`
- Start command: `npm start`

Keep API keys in the hosting provider's private environment settings. Do not put secrets in the HTML, ZIP, or GitHub repository.

## Notes

Aero Dash offers 22 level cards; the first 10 are playable and the other 12 are marked as coming soon. Aero Dash icons, quest progress, coin rewards, and chest timers are stored in the local browser. The playlist wallpaper is remotely hosted and needs an internet connection.
